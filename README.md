# Job Radar

Агент поиска работы на Claude Code. Раз в час он находит новые вакансии и оценивает каждую по полному тексту. Под подходящие он пишет письмо и CV, даёт их на проверку отдельному ревьюеру и отправляет сам: по email или через DOU и Djinni. Потом следит за ответами в Gmail и собирает всё в дашборд `dashboard.html`.

Цель не «разослать побольше». Нужно несколько точных откликов, где каждый факт подтверждён твоим профилем, а правила меняются только по реальным ответам работодателей.

Настроен на junior-роли в AI-автоматизации и LLM-интеграциях, рынки Украины и Германии. Под другую роль он меняется в одном файле, см. «Под себя».

## Что он делает и чего не делает

- Ищет вакансии: DOU, Djinni, Arbeitnow, поиск в интернете и карьерные страницы компаний, за которыми следит.
- Считает fit по требованиям вакансии и твоим фактам. Порог отправки 75 из 100.
- Пишет письмо на языке вакансии и собирает одностраничное CV (LaTeX) под неё. Перед отправкой их проверяет независимый субагент.
- Отправляет не больше 3 откликов за прогон и 6 в день. В одну компанию пишет не чаще раза в 60 дней.
- Отказы, тестовые и приглашения на интервью разбирает из Gmail. На интервью ставит в календарь «холды» и пишет черновик ответа, но **сам ничего не подтверждает**.
- **Никогда** не входит в аккаунты, не вводит пароли, не решает капчи.
- **Никогда** не выдумывает опыт: в письма и CV попадают только факты из раздела 9 `CLAUDE.md`.
- Пока раздел 9 не заполнен, агент ничего не делает: только напоминает его заполнить.

## Что нужно

- macOS (на Linux работает через cron).
- [Claude Code](https://claude.com/claude-code), вход через аккаунт claude.ai (не API-ключ). Тогда подтянутся коннекторы Gmail и Google Calendar.
- Chrome с расширением Claude: нужен для откликов на DOU и Djinni.
- TeX для сборки CV: `brew install --cask mactex-no-gui` и `brew install poppler`. Вместо MacTeX подойдёт `brew install tectonic`, тогда добавь `cv/tpl/bin` в PATH: там лежит обёртка `xelatex`.

## Установка

1. Склонируй репозиторий и зайди в папку:
   ```
   git clone <ссылка на этот репозиторий> ~/job-radar
   cd ~/job-radar
   ```
2. Проверь сборку CV. Команда должна вывести `ok ... pages=1`:
   ```
   cd cv/tpl && python3 build_cv.py --lang en --target "" --summary "Test" --out /tmp/t.pdf && cd ../..
   ```
3. Заполни профиль. Запусти `claude` в папке проекта, прикрепи своё CV и напиши:
   > Заполни раздел 9 и позиционирование в разделе 4 CLAUDE.md по моему CV, замени все плейсхолдеры в угловых скобках. Ничего не выдумывай: чего нет в CV, спроси у меня. Потом заполни cv/tpl/cv_en.tex и cv_de.tex теми же фактами и создай insights/profile через scripts/db.py (firstName, name, headline, city).

   Фото для CV необязательно: положи `cv/tpl/photo.jpg` или оставь без него.
4. В том же окне Claude выполни `/mcp` и проверь, что Gmail и Google Calendar подключены. Если имена инструментов не начинаются с `mcp__claude_ai_Gmail__`, попроси Claude поправить их в `.claude/settings.json` и `CLAUDE.md`.
5. Первый прогон сделай вручную, с Chrome:
   ```
   claude --chrome
   /job-run
   ```
   На DOU и Djinni войди в аккаунт сам, агент этого не делает.

## Автономный режим

```
bash scripts/install-macos.sh
```
Прогон запускается каждый час в :37, с 07 до 22 по времени Берлина. Мак не должен засыпать: Системные настройки > Аккумулятор > запрет сна при подключении к сети.

На Linux добавь строку в crontab:
```
37 7-22 * * * /bin/bash $HOME/job-radar/scripts/run.sh
```

О важном агент пишет тебе в Gmail с темой `[Job Radar] ...`: интервью, тестовое, отправленный отклик, отказ с причиной. В прогонах по расписанию Chrome обычно недоступен, поэтому отклики на DOU и Djinni копятся. Отправить их: `claude --chrome` и `/apply-browser`.

## Под себя

Все правила лежат в `CLAUDE.md`, Claude Code читает его сам.

- Другая роль: поменяй цель в начале файла, поисковые запросы в разделе 2 и канонические навыки в разделе 9.
- Другой город или часовой пояс: замени `<HOME_CITY>` в разделе 9 и «Berlin time» в `CLAUDE.md` и `scripts/run.sh`.
- Лимиты и порог: разделы 3 и 6.
- Своё iOS-приложение на дашборде, по желанию: впиши `APP_ID` в `scripts/appstore.py`.

## Что где

| Путь | Что это |
|---|---|
| `CLAUDE.md` | Все правила агента, разделы 0-10 |
| `.claude/skills/job-run/` | `/job-run`: один полный прогон |
| `.claude/skills/apply-browser/` | `/apply-browser`: отклики на DOU и Djinni через Chrome |
| `.claude/settings.json` | Разрешения для прогонов без вопросов. `rm`, удаление писем и `git push` запрещены |
| `data/` | База в JSON. Пишется только через `scripts/db.py` |
| `scripts/dashboard.py` | Собирает `dashboard.html` |
| `scripts/run.sh`, `scripts/install-macos.sh` | Прогон по расписанию и его установка |
| `cv/tpl/` | Шаблоны CV и `build_cv.py`. Готовые CV под вакансии ложатся в `cv/jobs/` |

## Приватность

После первого прогона в `data/`, `cv/`, `logs/` и `CLAUDE.md` появятся твои личные данные: телефон, письма, отклики. Каждый прогон коммитит их в локальный git. Если будешь пушить свою копию на GitHub, делай репозиторий **приватным**.
